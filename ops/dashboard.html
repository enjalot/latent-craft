Cloudflare connection

The latent-craft Standard bucket serves MONET through assets.latent.download. Uploads use a bucket-only key; metrics use a separate read-only token. Both stay on gsv, outside the repository and browser. No Worker is needed.

Credential setup for another installation
  1. Create a Cloudflare account, enable R2, and create a Standard bucket named latent-craft. This checkout creates a metered R2 subscription; do not choose Infrequent Access.
  2. In R2 → Manage API Tokens, create Object Read & Write credentials restricted to this bucket. Save the Access Key ID and Secret Access Key.
  3. From your laptop terminal, run the command below. It prompts privately over SSH and stores credentials in a mode-600 file on gsv, outside the repository. Do not paste secrets into chat, URLs or frontend settings.
ssh -t enjalot@gsv.local 'python3 /home/enjalot/code/latent-craft/ops/configure_r2.py'

For these usage charts, also create a separate Cloudflare API token with Account → Account Analytics → Read, restricted to your account. The prompt accepts that optional token too.

For publication, connect a custom domain to the bucket. The domain must be a zone in the same Cloudflare account. r2.dev is rate-limited and intended only for development. Do not change an existing site's DNS or nameservers until we review its records.

Publication requires GET/HEAD CORS and caching on the public asset bucket, verified exact byte ranges, and uploading the manifest last. No Worker or image-transformation subscription is needed.

What remains an estimate?

R2's storage run rate uses current bytes, not the billing cycle's average daily peak. Requests and free allowances are account-wide; origin requests exclude CDN cache hits. Modal reports usage before credits. HF shows the current configured Spaces, not your entire account invoice.

GCP traffic includes all destinations and is not equivalent to billed Internet egress. To show actual GCP costs, enable a Cloud Billing export to BigQuery and share its project.dataset.table identifier—not a secret key. We have Monitoring access already, but have not found a connected billing export.
